# Custodian Demo

A small Python application used for testing the CAB432 Repository Custodian agent.

## Running the application

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

The application starts on port 5000.

## Configuration

The application supports the following environment variables:

- `DEBUG`
- `APP_NAME`

See `docs/configuration.md` for more information.
